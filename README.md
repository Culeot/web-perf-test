# 设备性能测试 · Browser Performance Lab

在线浏览器性能体检工具:手机、平板、电脑打开即测,约 30 秒出报告。

**在线地址:https://culeot.github.io/web-perf-test/**

客户反馈网页卡顿?让客户打开这个页面跑一次体检,拿到性能分级和分项数据,开发者据此为这台设备定制优化方案。

## 功能

- **运算能力**:浮点、素数筛、数组排序、字符串处理四项基准,测浏览器内 CPU 真实算力
- **渲染帧率**:Canvas 粒子动画实测 FPS 与帧稳定性(网页是否跟手的关键)
- **DOM 构建**:节点创建与移除速度
- **本地存储**:localStorage 读写吞吐
- **网络画像**:连接类型、带宽、时延(基于 Network Information API)
- **设备画像**:设备类型、浏览器、平台、屏幕、内核数、内存
- **综合评分 + 分级**:相对中端桌面为 100 基准,分 S/A/B/C/D 五级
- **定制建议**:按综合档位、弱项、设备类型、网络、内存自动生成前端优化建议(带优先级)
- **报告分享**:一键复制纯文本报告,发给开发者即可对接定制

## 技术要点

- **单文件、零外部依赖**:全部 HTML/CSS/JS 内联,不引 CDN、字体、库。测试工具自身必须轻量,否则测的是"网页加载慢"而不是"设备性能"
- 数据全部在本机浏览器计算,**不上传、不留存**,无需后端
- 每次测试取 3 轮中位数,降低系统调度抖动影响
- 尊重 `prefers-reduced-motion`,支持隐私模式降级

## 开源调研

| 对标项目 | 说明 | 决策 |
|---|---|---|
| [jamesbachini/Browser-Benchmark-Tests](https://github.com/jamesbachini/Browser-Benchmark-Tests) | 单 HTML 测浏览器资源与性能的纯基准测试 | **参考其方法学,自研**(它无设备分级、无定制建议、无报告分享闭环) |
| Speedometer / Octane / Basemark 等传统基准 | 面向开发者的专业基准套件,体积大、无中文、无定制建议 | 不采用(目标用户是客户,需要开箱即用 + 中文报告) |

**结论:无现成项目同时满足「轻量单文件 + 中文 + 设备分级 + 定制建议 + 报告分享」,选择参考方法学自研。**

## 使用流程

1. 客户打开在线地址,点「开始体检」,保持页面在前台约 30 秒
2. 得到综合分、设备分级、分项成绩、定制建议
3. 点「复制体检报告」,把报告文本发给开发者
4. 开发者按报告中的档位与弱项做针对性优化

## 部署

推送到 GitHub 后开 Pages 即可(仓库根目录 `index.html`):

```bash
git init && git add . && git commit -m "init"
git remote add origin https://github.com/Culeot/web-perf-test.git
git push -u origin main
```

Pages 设置:Settings → Pages → Source 选 `main` 分支 `/`(root)。

## 说明

分数为相对参考值(中端桌面浏览器 = 100),受系统负载、后台应用、浏览器版本影响,建议连测两次取更准结果。结果仅评估浏览器内表现,不代表设备整体硬件水平。
